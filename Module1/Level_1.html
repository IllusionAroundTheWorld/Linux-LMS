Introduction to Linux & Open Source

1Simple Idea

In plain words: Linux is a free, open source operating system kernel anyone can inspect, modify, and share.
GNU PROJECT FOUNDER Richard Stallman (1983 • FSF / MIT)

Founded the GNU Project in 1983, creating free software tools and the GPL license.

LINUX KERNEL CREATOR Linus Torvalds (1991 • Univ. of Helsinki)

Created the open-source Linux operating system kernel in 1991 for personal computers worldwide.

Remember: The GNU General Public License ensures Linux source code remains permanently free for all global developers.
