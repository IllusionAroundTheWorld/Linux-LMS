Module 1 — Linux Fundamentals & Installation

  • Introduction to Linux & Open Source
  • History of Linux, Kernel & Distributions
  • Linux Architecture & Components
  • Installing Linux (Ubuntu / RHEL-based)
  • Virtual Machines & Dual Boot
  • Terminal & Desktop Overview
  • Linux Boot Process & GRUB
  • Systemd Targets & Runlevels
Module Outcome: Understand core Linux concepts, install a Linux system and explain how Linux boots and runs.

Module 2 — Linux Command Line & File System

  • Shell & Terminal Basics
  • File System Hierarchy (FHS)
  • Navigation Commands
  • Files & Directory Management
  • Viewing & Editing Files (vi / nano)
  • Wildcards, Redirection & Pipes
  • Hard Links & Soft Links
  • Help System — man & info
Module Outcome: Work confidently on the command line and manage files and directories across the Linux file system.

Module 3 — Users, Groups & Permissions

  • Users & Groups
  • useradd, usermod & userdel
  • Password Policies & Aging
  • File Permissions (rwx)
  • Ownership — chown & chgrp
  • Special Permissions — SUID, SGID, Sticky Bit
  • Access Control Lists (ACL)
  • umask
  • sudo & sudoers
  • Switching Users — su
Module Outcome: Create and manage users and groups and secure files with permissions, ACLs and sudo.
